# Website UI kit — Badsal & Fils Okikiola

A reference recreation of the company's B2B marketing homepage, composed from the
design-system primitives.

- **index.html** — static, self-contained preview (links `styles.css`). Open this to
  see the full page: top compliance bar, sticky header + nav, hero with quote +
  WhatsApp CTAs, three-up product grid, contact band with WeChat, footer.
- **Homepage.jsx** — the same layout built from the real components (`Button`,
  `ContactButton`, `NavItem`, `Badge`, `SectionHeader`, `ProductCard`) for consumers
  who want to fork it in code.

Language is French (Cotonou, Bénin). Product imagery is placeholdered — drop in real
photos of goods (anacarde, coton, karité) and the port of Cotonou.
