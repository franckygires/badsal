# BADSAL & FILS OKIKIOLA — Images à fournir pour le site

Document destiné au client. Objectif : rassembler **20 photos** (+ logo éventuel) pour
remplacer les visuels provisoires du site. Tout est prêt côté site : il ne reste qu'à
déposer les images.

---

## 📋 Consignes générales (à lire d'abord)

- **Format** : **JPEG** (`.jpg`) pour les photos. **PNG** ou **SVG** transparent pour un logo.
- **Qualité** : photos **nettes**, bien éclairées, en **haute résolution** (on se charge de
  les compresser/redimensionner — inutile de les réduire vous-même). Éviter les captures
  d'écran et les images floues/pixelisées.
- **Orientation** : respecter l'orientation indiquée (paysage / portrait) pour éviter les
  recadrages disgracieux.
- **Sujet centré** : l'image est recadrée automatiquement selon l'emplacement ; garder le
  sujet **au centre**.
- **Droits** : n'utiliser que des photos **dont vous détenez les droits** (vos propres
  photos, idéalement) ou libres de droits. Les photos réelles de vos produits/activités
  sont **fortement recommandées** (authenticité + confiance).
- **Nommage** : renommer chaque fichier avec le **nom indiqué** (colonne « Fichier ») —
  ça permet une intégration directe, sans confusion.
- **Envoi** : un dossier (Drive/WeTransfer) avec les fichiers nommés.
